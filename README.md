# University Room Fund

Информационная система учета аудиторного фонда университета.

## Назначение

Система предназначена для учета:
- корпусов университета;
- помещений;
- подразделений;
- площади и вместимости помещений.

## Основные сущности

- Building — корпус
- Department — подразделение
- Room — помещение

## Технологии

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
